JimJam — Pawan Mishra | GitHub Pages bundle

READY TO UPLOAD
Upload the contents of this folder to the root of your GitHub repository.
Keep index.html, styles.css, script.js, and the assets folder together.
Upload the extracted files, not the ZIP and not an enclosing folder.
No installation, npm command, build step, API key, or external font service is needed.

PUBLISH
1. Upload all extracted contents and commit the changes to your repository.
2. Open the repository's Settings > Pages.
3. Under Build and deployment, choose Deploy from a branch.
4. Select main (or the branch where you uploaded the files) and / (root).
5. Save. Once deployment completes, GitHub Pages will show the site link.
Official instructions: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
